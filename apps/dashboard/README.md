# ARRAY LAB 可视化原型

本地 React + TypeScript + Plotly 界面，独立于 Python 仿真环境。系统指标使用固定种子的合成数据，不代表 Sionna 仿真。方向图采用标准阵子近似和理想阵列因子。

## 运行

安装 Node.js 20.19+ 或 22.12+，在本目录执行：

```powershell
npm install
npm run dev
```

打开终端显示的本地地址。构建检查使用 `npm run build`。

## 功能

- 天线阵列与方向图、系统仿真两个功能标签；配置与结果切换保留状态。
- Beginner / Expert、JSON 配置导入导出、配置变更提示。
- 用户和小区筛选、表格排序、CSV 导出、CDF 实验叠加、slot 区间选择。
- Plotly 工具栏支持缩放、重置和 PNG 导出。

`src/data.ts` 集中定义配置、结果与示例数据提供函数；真实仿真接入时替换数据生成入口，保持页面消费的结果结构。当前传播模型、调度与 CSI 选项为占位；合成系统数据只使用带宽、站间距、用户数、slot 数、目标错误率和种子。阵面和功率不会影响合成系统性能。

IBLER 为首次传输 TB 错误率。MCS 和 Rank 的逐 slot 值为整数，用户汇总显示已调度样本均值。RSRP 为用户级示例值，不提供时序。时序 IBLER 显示单次首次传输错误指示（0/100%），非滑动窗口估计。

首版不包含账号、后台任务或联网服务。所有依赖通过本地安装加载，运行时无需访问 CDN。
